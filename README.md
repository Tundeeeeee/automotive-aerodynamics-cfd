# Automotive Aerodynamics — Ahmed Body CFD Simulation

## Project Overview

A collaborative automotive engineering project completed at the University of Windsor, investigating the aerodynamic performance of an Ahmed body using Computational Fluid Dynamics (CFD).

The study examines how changes in rear slant angle affect aerodynamic drag, lift, and airflow characteristics. Numerical simulations were performed using STAR-CCM+, with results compared against published experimental data.

## Project Objectives

- Simulate airflow around a simplified automotive Ahmed body.
- Investigate rear slant angles of 25° and 12.5°.
- Evaluate aerodynamic drag and lift coefficients.
- Examine airflow separation and wake characteristics.
- Compare numerical simulation results with experimental data.

## Tools & Technologies

- STAR-CCM+ — Computational Fluid Dynamics
- CFD Modeling and Simulation
- Computational Meshing and Mesh Refinement
- K-Omega Turbulence Modeling
- Aerodynamic Drag and Lift Analysis

## Methodology

1. Develop a two-dimensional Ahmed body model in STAR-CCM+.
2. Define the computational domain and model geometry.
3. Generate and refine the computational mesh.
4. Apply fluid properties and boundary conditions.
5. Configure the turbulence model and unsteady flow solver.
6. Simulate the airflow around the Ahmed body.
7. Analyze aerodynamic drag and lift coefficients.
8. Compare simulation results against experimental findings.
